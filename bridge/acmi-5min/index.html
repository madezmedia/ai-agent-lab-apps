ACMI in 5 minutes

ACMI is a free, open-source memory layer for AI agents. Every agent, project or task gets three slots:

ProfileWho it is
role, settings, owner
SignalsWhat's true now
status, blockers, links
TimelineWhat happened
every event, in order

Your agents read these at the start of a session and write to them as they work. That's the whole idea.

1

Create a free memory database

Go to console.upstash.com, create a Redis database (free tier is fine), open the REST API tab and copy UPSTASH_REDIS_REST_URL and UPSTASH_REDIS_REST_TOKEN. Treat the token like a password.
2

Install the ACMI server

npm install -g @madezmedia/acmi-mcp
3

Connect it to your AI tool

Claude Code: 
claude mcp add acmi acmi-mcp \
  -e UPSTASH_REDIS_REST_URL=https://<your-id>.upstash.io \
  -e UPSTASH_REDIS_REST_TOKEN=<your-token>

Claude Desktop / Cursor / Cline / Windsurf: add this to your MCP settings, then restart the app.

{
  "mcpServers": {
    "acmi": {
      "command": "acmi-mcp",
      "env": {
        "UPSTASH_REDIS_REST_URL": "https://<your-id>.upstash.io",
        "UPSTASH_REDIS_REST_TOKEN": "<your-token>"
      }
    }
  }
}
4

Give your agent a memory

Paste this into your AI tool: 
Using the ACMI tools:
1. Write a profile for agent:my-first-agent with actor_type "agent"
   and role "personal assistant".
2. Log a timeline event on agent:my-first-agent with kind "spawn"
   and summary "[spawn @me] first agent online".
3. Set a signal current_task = "learning ACMI".
5

Close the chat. Open a new one.

Bootstrap agent:my-first-agent from ACMI and tell me what it was doing.
If it answers "learning ACMI", your agent now remembers between sessions. 🎉

Source code and docs: github.com/madezmedia/acmi
