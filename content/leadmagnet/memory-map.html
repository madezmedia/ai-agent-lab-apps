Stop your AI agents from forgetting.

Claude, Cursor and every other AI tool start each chat from zero. The fix is one shared memory that every agent reads when it starts and writes to as it works. Here's the whole model on one page.

The 3-slot memory model

Profile

Who the agent is. Changes rarely. 
{
  "role": "coding agent",
  "owner": "you",
  "rules": ["tests before push"]
}

Signals

What's true right now. Overwritten. 
{
  "current_task": "fix login bug",
  "blocked_on": null,
  "last_heartbeat": "09:14"
}

Timeline

What happened, in order. Append-only. 
09:02 picked up login bug
09:10 found cause: expired token
09:14 opened fix, waiting review

The agent team, mapped

One agent routes the work. The others build, run 24/7 or write code. They all read and write one memory, so each one knows what the others did yesterday.

4 rules that make it work

Read first. Every session starts by loading the agent's Profile, Signals and recent Timeline.
Write as you go. Log each real step to the Timeline, not just the final answer.
Signals are "now". Overwrite them; never let two agents keep separate versions of the truth.
One ID per job. Tag related events with the same ID so you can follow a task across agents.

Mad EZ Media · Set it up free

Your first agent that remembers.

About 5 minutes. Free database tier, free open-source tools. Works with Claude Code, Claude Desktop, Cursor, Cline and Windsurf.

1

Create a free memory database

At console.upstash.com, create a Redis database (free tier is fine). From the REST API tab, copy UPSTASH_REDIS_REST_URL and UPSTASH_REDIS_REST_TOKEN. Treat the token like a password.

2

Install the ACMI server

npm install -g @madezmedia/acmi-mcp
3

Connect it to Claude Code

claude mcp add acmi acmi-mcp \
  -e UPSTASH_REDIS_REST_URL=https://<your-id>.upstash.io \
  -e UPSTASH_REDIS_REST_TOKEN=<your-token>

Cursor / Claude Desktop / Cline / Windsurf: add the same two env vars to an "acmi" entry in your MCP settings, then restart the app.

4

Give your agent a memory

Using the ACMI tools: write a profile for agent:my-first-agent
(role "personal assistant"), log a "spawn" event, and set the
signal current_task = "learning ACMI".
5

Close the chat. Open a new one.

Bootstrap agent:my-first-agent from ACMI and tell me what it was doing.

If it answers "learning ACMI", your agent now remembers between sessions.
