## Main description

**Your AI agents keep forgetting. Fix that once.**

Every new chat starts from zero. You re-explain your project, each tool only knows its own
history, and work gets redone. AI Agent Lab shows you how to run a *team* of AI agents that
share one memory, so they pick up where they left off and hand work to each other.

**What you get**

- **A new agent build every week**: step-by-step builds from the real agent setup Mad EZ Media runs its business on.
- **Drop #1: "Your AI Agent Team: The Map"**: see how the whole team is organized, then set up your first agent that remembers its work between sessions (about 30 minutes).
- **Starter Kit files**: the ready-made files, included in the Lab's Files tab.
- **Private member chat + forum inside the Lab**: ask questions, share builds, get unstuck.

**How it works**

Every agent gets three memory slots: **Profile** (who it is), **Signals** (what's true now)
and **Timeline** (what happened, in order). It's built on ACMI, an open-source (MIT) memory
layer, and works with Claude Code, Claude Desktop, Cursor, Cline and Windsurf.

**Who it's for**

People already using AI tools who are tired of starting over in every chat and want their
agents to work together, not in silos.

**$39/month. Cancel anytime.**

**How often is new content added?**

**What if I get stuck?**
